Windows 端 NapCat 配置与连接教程

本工具通过 NapCat（OneBot 11 协议） 读取你所在 QQ 群的成员名单，找出同时出现在多个群里的人。这份教程手把手教你，在 Windows 电脑上把 NapCat 装好、连上本工具并跑通第一次分析。

〇、开始之前，你需要知道什么

先讲清楚三个角色，避免后面绕晕：

1
NapCat —— 一个「翻译官」。它登录你的 QQ，并把 QQ 的群成员接口翻译成标准的 OneBot 11 HTTP 接口，供别的程序调用。它是本工具的「数据来源」。
2
本工具（qq-group-overlap） —— 分析器。它连上 NapCat 的 HTTP 接口，拉取群成员名单，做重合分析并给出排行。
3
连接方式 —— 本工具用的是 HTTP POST（不是 WebSocket）。所以教程的核心，就是让 NapCat 在 127.0.0.1:3000 开一个 OneBot HTTP 服务，本工具带着 token 去访问它。

一、安装 Python

本工具用 Python 编写，且只用标准库，无需额外依赖。

  1. 打开 Python 官网下载页：https://www.python.org/downloads/windows/
  2. 下载 Python 3.11 或更新版本的 64 位安装包（例如 python-3.12.x-amd64.exe）。
  3. 运行安装包，务必勾选 Add Python to PATH，再点 Install Now。
  4. 安装完成后，按 Win + R，输入 cmd 回车，在命令行里验证：
python --version

看到类似 Python 3.12.x 的输出即成功。

二、下载并安装 NapCat

NapCat 的官方仓库是 NapNeko/NapCatQQ。Windows 下推荐用官方一键安装包。

  1. 打开 Releases 页面：https://github.com/NapNeko/NapCatQQ/releases
  2. 找到 Windows 一键安装包（名称通常类似 NapCat.Shell.Windows.OneKey.zip 或带 OneKey 字样的包），下载并解压。
  3. 解压后双击 NapCatInstaller.exe，等待它自动完成配置。
  4. 安装完成后，会在目录里生成一个 NapCat.XXXX.Shell 之类的目录，进入它。
两种安装方式怎么选 一键包（OneKey）：适合新手，自动下载并配置 QQ 客户端环境，最省事。
Shell 版：需要你自己电脑上已经装了新版 NTQQ（腾讯 QQ），NapCat 会去调用它。适合已经有 QQ 客户端的情况。

三、扫码登录 QQ

  1. 在 NapCat.XXXX.Shell 目录里，双击 napcat.bat（一键包也可能是 bootmain.exe 或 NapCatWinBootMain.exe）。
  2. 启动后，控制台会弹出一个二维码（或自动拉起 QQ 登录窗口）。用你的手机 QQ 扫码登录。
  3. 登录成功后，日志里会出现类似这样的一行：
[WebUi] WebUi User Panel Url: http://127.0.0.1:6099/webui?token=XXXX

记下这个地址——这就是 NapCat 的 WebUI（网页管理面板）。浏览器打开它，就能配置接口了。

四、开启 OneBot 11 HTTP 服务

这是最关键的一步。本工具通过 HTTP 接口访问 NapCat，所以要在 WebUI 里开一个 HTTP 服务。

  1. 浏览器打开上一步记下的 WebUI 地址（形如 http://127.0.0.1:6099/webui?token=XXXX）。
  2. 在左侧找到 「网络配置」（或 Network Config）。
  3. 点 「新建」，选择 「HTTP 服务器」（OneBot 11 / HTTP Server）。
  4. 按下面填配置：
配置项填什么说明
名称 / Nameqq-overlap随便起，方便辨认
Host / 地址127.0.0.1只监听本机，安全
Port / 端口3000本工具的默认端口
Token / 鉴权（自定义一串）如 qq-overlap-local，下一步要用
  1. 点 「保存」，并确认这个 HTTP 服务器右上角的开关是 打开 状态。
  2. 保存后 NapCat 日志应出现类似 HTTP 服务: 127.0.0.1:3000 已启动 的提示。
为什么端口是 3000、Host 是 127.0.0.1 本工具的 GUI 和命令行默认访问 http://127.0.0.1:3000。端口和地址要和这里一致。不要把 Host 设成 0.0.0.0——那会对外网开放，非常危险，127.0.0.1 就够本机用了。

五、连接本工具并启动 GUI

回到本工具的项目目录。连接靠一个环境变量 ONEBOT_ACCESS_TOKEN，把你在上一步设置的 token 填进去。

方法 A：双击启动（推荐）

  1. 在项目根目录，找到 scripts\start-gui.bat。
  2. 第一次需要先设置 token。打开命令行（cmd），进入项目目录：
cd /d C:\你的路径\qq-group-overlap
set ONEBOT_ACCESS_TOKEN=qq-overlap-local
scripts\start-gui.bat

之后如果 token 不变，也可以直接双击 start-gui.bat（需先在系统环境变量里设好 ONEBOT_ACCESS_TOKEN）。

方法 B：设置系统环境变量（一劳永逸）

  1. Win + R → 输入 sysdm.cpl 回车，打开系统属性。
  2. 「高级」→「环境变量」→ 在「用户变量」里点「新建」。
  3. 变量名填 ONEBOT_ACCESS_TOKEN，变量值填你的 token（如 qq-overlap-local）。
  4. 确定保存，重开命令行窗口使其生效。
Token 只存在环境变量里 本工具不会把 token 写进任何快照或报告文件，它只从环境变量 ONEBOT_ACCESS_TOKEN 读取。这样你发到 GitHub 的公开仓库里也不会泄露 token。

六、首次分析：从拉取成员到看结果

启动 GUI 后，按这个顺序走一遍：

1
左上角搜索并选择至少 2 个群。单击选一个，Ctrl 增减选择，Shift 连选一段。
2
点 「只刷新已选群等级」。这一步会通过 NapCat 拉取这些群的成员和等级，并自动排除你自己。
3
选择算法预设，或直接改评分公式（默认「共同群数 + 各群等级对数加分」）。
4
点 「开始评价」。结果分页显示，没有人数上限。
5
需要完整名单时，点 「导出全部结果」 保存成 CSV。

也可以不打开 GUI，用命令行直接跑：

cd /d C:\你的路径\qq-group-overlap
set ONEBOT_ACCESS_TOKEN=qq-overlap-local
set PYTHONPATH=%CD%\src
python -m qq_group_overlap live

live 命令会列出你所有群，输入群序号（如 1,3,8）就会拉取并生成报告。

七、常见问题（FAQ）

1. 点「只刷新已选群等级」报错「无法连接 NapCat」

  • 确认 NapCat 还开着、QQ 已登录。
  • 确认 WebUI 里 HTTP 服务器端口是 3000、开关是开的。
  • 确认环境变量 ONEBOT_ACCESS_TOKEN 的值和 WebUI 里设置的 token 完全一致。
  • 用命令验证接口是否通：
curl -X POST http://127.0.0.1:3000/get_login_info -H "Content-Type: application/json" -H "Authorization: Bearer qq-overlap-local" -d "{}"

若返回了你的 QQ 信息（而不是报错），说明 NapCat 侧没问题。

2. 端口 3000 被占用

可以在 WebUI 里把 HTTP 服务器端口改成别的（如 3001），然后启动本工具时加 --api 参数：

scripts\start-gui.bat --api http://127.0.0.1:3001

3. 启动报「找不到 python」

说明 Python 没装好或没加入 PATH。回到 第一步 重装，安装时勾选 Add Python to PATH，装完重开命令行。

4. 二维码扫不出来 / 登录不上

NapCat 偶尔会因 QQ 版本或网络问题登不上。可以：换扫码方式、稍等重试、更新到最新版 NapCat、或改用 Shell 版配合已安装的最新 QQ。

5. 群成员的「等级」显示缺失

这是正常的。旧快照或某些群没有等级数据，工具会明确显示「缺失」而不是悄悄填 0。点「只刷新已选群等级」后，有等级的群会补上。

八、隐私与安全提醒

  • 成员快照里有 QQ 号和群名片，属于私密数据，不要上传 GitHub、不要公开分享原始快照。
  • 本项目 .gitignore 已排除 runtime/、report/、snapshots/ 和 *.private.json，提交前请确认这些目录确实没被纳入版本控制。
  • 要把报告发给别人时，用 --mask-ids 参数给 QQ 号打码。
  • NapCat 的 HTTP 服务请始终保持 127.0.0.1 监听，不要改成 0.0.0.0，否则局域网甚至公网都能访问你的 QQ 接口。
  • 共同群多只能说明兴趣圈层可能重合，不代表对方一定愿意被联系。
